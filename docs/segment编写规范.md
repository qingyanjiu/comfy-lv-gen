# 分镜编写规范（segments[].body）

> 这份文档只说一件事：**每一段的 `body` 该怎么写**。
> 人物身份、画风、胶片质感、首尾帧承接、眼神频率、画幅、时长、过场方式——全部由公用配置统一处理，
> 你不用写、不用填、也改不到。你只需要把「这一段画面里发生什么」写清楚。

---

## 一、body 的唯一职责

`body` 回答一个问题：**这 8 秒钟，画面里的人做了什么、镜头怎么摆、光从哪来、周围是什么。**

三句话原则：

1. 只写**这一段**发生的事，不写上一段、不写下一段。
2. 只写**看得见**的东西（身体、手、脚步、视线、光、物件），不写心理活动、不写剧情解释。
3. 只写**这一段独有**的信息，公用配置已经写过的内容一个字都不重复。

---

## 二、一段 body 的骨架

推荐固定四块，用空行隔开。不需要小标题的短段可以只写动作，但机位和光线最好别省——
H3 对「镜头在哪、光从哪来」的响应远强于对抽象形容词的响应。

```
她从铁门边起步，缓步走向画面右侧的金属栏杆，右手抬起搭在栏杆上。

[机位] 摄影机跟随她向右平移，保持中景，腰部高度，始终在她左侧后方。

[光线] 与上段同一档橙红夕阳，只有云层亮度极轻微变化，绝不入夜、不转蓝调。

[场景] 粗糙水泥天台，地面浅浅积水，右前方灰白金属栏杆，栏杆外楼群层叠。
```

- **动作**：谁、从哪到哪、身体哪个部位在动、动完停在什么姿态。一句一个动作，按时间顺序写。
- **机位**：摄影机的位置、高度、侧别、景别、是否移动。这一块决定构图稳不稳。
- **光线**：本段的光线状态；连续段只写「与上段一致 + 有没有变化」。
- **场景**：本段用得到的物件与方位。空间结构以空镜板为准，这里只补充「人和什么发生关系」。

---

## 三、动作怎么写

### 3.1 写「持续、缓慢、可见」的动作

H3 的实际输出是**长时间近乎静止 + 少数瞬间明显位移**。写「猛地转身 / 快速奔跑 / 剧烈挥手」
不会得到快动作，只会得到一段卡顿的形变。稳妥写法是**一个缓慢动作贯穿全段**：

- ✅ 她缓步向前走了三步，右手抬起搭在栏杆上，随后停住。
- ❌ 她快步冲向栏杆，猛地转身，又迅速跑开。

### 3.2 动作要落在具体部位

- 脚步：起步 / 停步 / 重心转移 / 步幅
- 手部：抬起 / 搭上 / 松开 / 垂下
- 肩与躯干：转向 / 前倾 / 起伏
- 头部与视线：转动 / 低垂 / 抬起 / 落点

只写「她很自然地走动」等于没写，模型会自己发挥。

### 3.3 段与段之间不要重新起步

上一段在走，这一段就接着走；上一段手搭在栏杆上，这一段手还在栏杆上。
**不要写「她重新开始走」「她摆好姿势」**——段首承接由系统自动完成，你只要保证动作状态是延续的。

### 3.4 一段只推进一件事

8 秒装不下「推门 → 走出 → 转身 → 撑伞 → 离开」。一段一个动作单元，多出来的拆成下一段。

## 四、机位怎么写

按这五项写全，缺一项模型就自由发挥：

| 项 | 例子 |
|---|---|
| 位置 | 她左侧斜后方 / 正前方 / 画面右前方 |
| 高度 | 腰部高度 / 胸部高度 / 略高于头顶俯拍 |
| 侧别 | 保持在人物左侧，不跨到另一侧 |
| 景别 | 中景 / 上半身近景 / 面部近景 / 腰部细节 |
| 运动 | 固定 / 缓慢推进 / 同速跟拍 / 轻微右移 |

要点：

- **只改摄影机，不改人物**：切景别时写明「仅改变机位与构图，人物保持原步态与方向」。
- **不跨轴**：同一段内不要从人物左侧绕到右侧；需要换侧就换段、用转场。
- **别写复杂运镜**：环绕、希区柯克变焦、手持甩镜这类，H3 做不出来，写了只会让画面飘。
  要「有运镜感」，用「缓慢推进 / 同速跟拍 / 轻微平移」这三个词。
- 固定机位是最稳的。不确定就写固定机位 + 明确景别。

---

## 五、光线与场景怎么写

### 5.1 光线

- 连续段：`[光线] 与上段完全一致，暖金侧光从左后方来，亮度不变。`
- 变化段（用转场切时间/天气）：`[光线] 入夜，蓝调环境光 + 远处暖色灯点，人物侧脸一道暖边光。`
- **不要写**画风词：35mm、胶片颗粒、电影感、柯达色、浅景深虚化……这些在公用配置里，逐段写会互相打架。

### 5.2 场景

- 只写本段人和物件的**关系**：手搭在哪、脚踩在什么上、身体挡住什么。
- 建筑走向、道路宽度、家具布局属于空镜板，文字写不过图，写多了反而让模型改结构。
- 要新物件就写清「方位 + 材质 + 与人物的相对位置」：`右前方灰白金属栏杆，齐腰高，她右手搭在横杆上`。

## 六、眼神与表情：只写本段的落点

公用配置已经统一写好「自然眨眼频率 + 眼神光（catchlight）+ 不空洞不木然」。**body 里不要重复这三项**，
只写这一段特有的视线去处和微表情：

- ✅ 她的视线落在身前的地面，随后慢慢抬向前方的门。
- ✅ 眉头轻轻收紧，嘴唇抿了一下，随即放松。
- ❌ 她的眼睛每 3–4 秒眨一次，瞳孔带细微反光点（catchlight），眼神不空洞。—— 这是公用配置的活，重复会稀释权重。

写的时候只回答：**这一段她在看哪里？脸上哪块肌肉动了一下？**

### 想让角色眨眼：必须写成这一段的动作

实测（2026-11-13，5 秒 / 0.8MP / 同一 seed / 同一参考图，四组对照）：

| 写法 | 结果 |
|---|---|
| 只在公用 head 里写「每 3–4 秒眨一次」 | 5 秒内 **0 次**闭眼，眼睛越眯越垂 |
| 公用 head 精简到 235 字，body 仍不写动作 | 1 次约 0.4–0.5 秒的闭眼（偶发） |
| body 写「缓慢地闭上双眼，停留约半秒，再缓缓睁开」 | 确实闭眼，但被拉成 **约 2 秒**的慢动作（表演级闭眼，不是眨眼） |
| body 写「她很快地眨了一下眼，眼睑迅速合拢又立刻睁开」 | **1 次约 0.5 秒的闭眼，最接近自然眨眼** ✅ |

要点：

- **眨眼写在 body，不要写成「缓慢」**。写「缓慢闭上」会得到 2 秒的闭眼表演；写「很快地眨一下、迅速合拢又立刻睁开」才会被压到 0.5 秒左右。
- **5 秒段可靠做到 1 次**。想要更频繁只能拆段，或接受偶发。
- **公用 head 里的眨眼频率句对 H3 基本无效**（0 次），它只稳定响应 catchlight、视线方向这类静态外观。别指望靠它。顺便把眼睛定住：body 里加一句「眼睛正常睁开、看着前方」，能压住那种一路眯下去的默认状态。

## 七、多人段落：关系必须写进 body

参考图只告诉模型「这个人长什么样」，不告诉他「这两个人怎么站」。人物关系是 `body` 的责任：

```
{pic:1} 的女生站在画面左侧，面朝右；{pic:2} 的男生在画面右侧，半侧身面向她，
右手搭在她左肩上，她的左肩被遮住一部分。两人相距约半步。
```

必须写全：**谁在左/右、各自朝向、有没有接触、谁挡住谁、相距多远**。
人一多脸就小，多人段落优先用中近景；0.5MP 下全身景锁不住脸。

指人物一律用 `{pic:1}` / `{pic:2}`，**不要写死 `<Picture 1>`**：链式段的首帧会占掉 P1，
人物整体后移一位，写死编号就会指到首帧上。（`{pic:plate}` 指空镜板，一般不用在 body 里。）

## 八、篇幅

- 一段 8 秒 ≈ **100–160 字**（网页「每段字数≈130」就是按这个估的）。写太短模型自由发挥，写太长后半段被忽略。
- 四块之间用空行分隔，读起来是一段一段的指令，不是一篇作文。
- 不要写形容词堆叠（唯美、高级、氛围感、大片感），模型不认，还占字数。

---

## 九、不要写什么（公用配置已覆盖）

| 不用写 | 原因 |
|---|---|
| 不换人 / 不融脸 / 保持身份一致 | 全片统一约束 |
| 严格继承上一段真实尾帧 / 首帧承接 | 链式段自动生效，首段自动不生效 |
| 段尾收住 / 段首静息 / 留 0.5 秒 | 全片统一 |
| 眨眼频率 / 眼神光 catchlight | 全片统一 |
| 画风、胶片颗粒、35mm、色调、质感 | 全片统一 |
| 禁止项清单（不要多余手指、不要穿模…） | 全片统一 |
| 人物长相、发型、服装 | 参考图 + 本片设定 |
| 场景建筑结构、道路走向 | 空镜板 |
| 秒数、帧率、画幅、画质、过场方式 | 公用配置 |

写了也不会报错，但会**稀释真正有用的信息**，还可能和公用约束打架。

## 十、写完自查

- [ ] 这一段只写了这一段的事？
- [ ] 有一个贯穿全段的**可见动作**，不是一堆静态描述？
- [ ] 机位写清了位置 / 高度 / 侧别 / 景别 / 运动？
- [ ] 切景别时写明了「只改摄影机，不改人物动作」？
- [ ] 光线写了「与上段一致」还是「怎么变」？
- [ ] 眼神只写了本段落点，没抄眨眼频率和 catchlight？
- [ ] 多人段落写清了站位、朝向、接触点、遮挡？
- [ ] 没有出现画风词、禁止项、承接句、人物长相、场景结构？
- [ ] 字数在 100–160 之间？

## 十一、完整范例

同一座黄昏天台，三段连续动作。注意每段只推进一件事，机位只在段与段之间变。

### 第 1 段（首段，无承接）

```
她缓缓推开一扇斑驳生锈的铁门，从门后走出来，铁门在身后缓慢回落。

[机位] 摄影机在斜后方腰部高度轻微仰拍，人物位于画面偏左，极平稳地缓慢向前推进。

[光线] 橙红夕阳沉在远处楼群之间，暖金色轮廓光勾出发丝与肩膀边缘。

[场景] 粗糙灰色水泥天台，地面有浅浅积水，右前方灰白金属栏杆，栏杆外楼群层叠延伸到地平线。
```

### 第 2 段（承接上段尾帧）

```
她从铁门边起步，缓步走向画面右侧的金属栏杆，右手抬起搭在栏杆上。

[机位] 摄影机跟随她向右平移，保持中景，腰部高度，始终在她左侧后方。

[光线] 与上段同一档橙红夕阳，只有云层亮度极轻微变化，绝不入夜、不转蓝调。
```

> 没有写「严格继承上一段尾帧」，也没有写「她从静止开始」——承接是自动的，写了反而多一个矛盾点。

### 第 3 段（换时间，用转场切）

```
同一座天台的夜景，她侧身站在栏杆前，风吹动长发，右手仍扶着栏杆。

[机位] 固定机位近景侧脸特写，浅景深，背景灯点虚化成光斑。

[光线] 蓝调夜景，冷色环境光 + 暖色城市灯点，人物侧脸有一道暖边光。
```

> 用 `link.mode = "transition"` 切过来，所以这里写「同一座天台的夜景」交代新时间，
> 不需要写承接，也不需要重复人物长相。

### 多人段落

```
{pic:1} 的女生站在画面左侧，面朝右；{pic:2} 的男生在画面右侧，半侧身面向她，
右手搭在她左肩上，她的左肩被遮住一部分。两人相距约半步，都没有说话。

[机位] 固定机位，胸部高度，中近景，两人都在画内，女生略靠前景。

[光线] 室内暖白顶光偏左，两人脸侧各有一道柔和阴影。
```

## 十二、常见问题速查

| 症状 | 原因 | 改法 |
|---|---|---|
| 人物几乎不动 | 写的是状态不是动作 | 换成「走三步 / 抬手 / 转身」这类有起止的动作 |
| 动作突然跳一下 | 一段塞了多个动作或写了快速动作 | 一段一件事，节奏改成「缓慢」 |
| 画面自己推拉镜头 | 机位没写全，或写了复杂运镜 | 补位置/高度/侧别/景别，运镜只留「固定/缓慢推进/同速跟拍」 |
| 换景别后人物重新起步 | 没写「人物动作保持连续」 | 切景别处补一句「仅改变机位，人物保持原步态」 |
| 场景结构和空镜板不一样 | body 里写多了建筑/布局 | 删掉场景结构描述，只留人物与物件的接触关系 |
| 人物脸崩 / 换脸 | 段内景别太远或动作太大 | 改中近景，减小动作幅度，必要时加参考图 |
| 两人衣服越跑越像 | 两人外观太接近 | 在 body 里写死各自衣着差异（女生白裙 / 男生深色外套） |
