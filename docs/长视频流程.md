# 长视频制作工作流（规划草案 v0.1）

> 目标：把「写分镜 → 生成 → 修缝 → 拼接 → 后期」这条链路固化成可重复执行的流程，
> 让长视频从「碰运气」变成「按表执行」。本文件是活的，跑一轮补一轮。
>
> 提示词怎么写的规则单独整理在 `提示词指南.md`。

---

## 0. 能力边界（先接受，别硬刚）

| 维度 | 这套流的稳定区间 | 超出后会发生什么 |
|---|---|---|
| 单段时长 | 6~10 秒 | >10s 肢体崩坏、步态错乱概率明显上升 |
| 总时长 | 60~120 秒 | 更长的链条身份/服装漂移累积加重，且耗时段数线性增长 |
| 人物数 | 1 人为主 | 多人交互不可控 |
| 镜头 | 固定或缓动 | 推拉摇移需要赌运气，建议后期加 |
| 内容类型 | 一镜到底的动线（走、停、坐、转身） | 复杂叙事、对话、特写切换不适合 |

> 认知前提：H3 这类模型单次只能稳定出几秒，**长视频 = 分镜拼接**。这不是这套流的缺陷，
> 它的价值恰恰是把拼接过程中的接缝修复、QA、定点重渲自动化了。

---

## 1. 两种分镜模式（按项目选一种）

### 模式 A：链式连续镜头（现在这套 config 就是这个）
- 每段接上一段真实尾帧（`chain_segments: true`）
- 优点：动作绝对连贯，像一镜到底；适合「走一段路」「一个连续动作」
- 缺点：漂移会累积；坏一段后面的都受影响
- 适用：60s 以内的单场景连续动线（你上次那条 100 秒就是这个）

### 模式 B：分镜独立镜头
- 每段都从参考图出发（`continue_from_previous: false`），靠参考图 + 提示词保一致性
- 段与段之间用 `transition_mode: fade / generated` 缝合
- 优点：无累积漂移，坏一段单独重跑；可以跳场景、跳时间
- 缺点：转场感明显，动作不连续
- 适用：多场景叙事、MV、分镜感强的片子

**混合打法（推荐）**：主戏份用模式 A 连成 3~5 段的小段落，段落之间用模式 B 的切点隔开。

## 2. 工作流七步

### S1 写分镜表
用表格把片子拆成段，每段一行：

| 段 | 秒数 | 类型 | 要写什么 | 链式 | 转场 |
|---|---|---|---|---|---|
| 1 | 6 | 开场 | 完整描述：身份+服装+场景+机位+动作 | - | - |
| 2~4 | 6 | 延续 | 只写「相对上一段的变化」 | 是 | - |
| 5 | 6 | 切点 | 重新完整描述新场景 | 否 | fade |
| ... | | | | | |

**写作量真相**：60 秒 10 段 ≈ 1 个完整段 + 8 个变化句 + 1 个切点，没有想象中大。

### S2 准备参考图
- 1~2 张清晰正脸 + 1 张服装/全身（现在用 `image.png`、`image (5).png`）
- 参考图是全片身份的唯一锚点，换人 = 换参考图

### S3 单段验证（必做，别跳过）
用 UI 或 `--limit 1` 只跑第 1 段，检查：
- [ ] 人物像不像参考图
- [ ] 服装、场景对不对
- [ ] 机位是否固定、人物是否全身入镜
- [ ] 记下这一段的耗时（后面算总时间）

### S4 小批量验证
跑前 3 段，重点看**接缝**：
- 段1→段2 有没有跳变
- 动作是不是接上了（有没有「定格后突然动起来」）

### S4.5 关键帧人工确认（默认开启，强烈建议别关）

Director 节点的 `stage` 默认 = **「关键帧 → 确认 → 视频」**：

1. 点运行后只渲染首尾关键帧（每段 2 秒小草稿，很快）
2. 渲染完自动**停下来**，面板顶部出现黄色横幅「关键帧已生成，等待你确认」
3. 逐张看，每张下面三个按钮：

| 按钮 | 作用 | 什么时候用 |
|---|---|---|
| **替换** | 上传你自己满意的图，直接顶掉这一帧（旧图存进 `*_original`） | 你有现成的构图/姿势图，或 AI 画歪了但你知道想要什么 |
| **重画** | 清空这一帧的缓存签名 + 加一次 attempt，下次关键帧阶段换 seed 重出 | AI 画得不对但你也说不清要什么，想再摇一次骰子 |
| **还原** | 把「替换」时存下的 AI 原图放回去，**不跑 GPU、不排队重画** | 替换错了想反悔 |

> ⚠️ 「还原」只在**有原图**时可用。用 `pipeline.py push` 灌进来的
> `segNN_*_manual.png` 没有原图（不是从「替换」进来的），所以那一侧按钮是灰的——
> 想按提示词重出请点「重画」，想换图请点「替换」。

4. 全部满意后点 **「确认关键帧，生成视频」** → 才开始烧钱的分段视频渲染

**面板里直接改秒数和提示词**

关键帧卡片底部还有一行：`5 秒 · 提示词摘要 · 改词`。点「改词」（或点摘要文字）会在
关键帧网格上方展开编辑器：左边是这一段的首帧/尾帧缩略图，右边三个文本框（主提示词 /
首帧提示词 / 尾帧提示词），顶上是秒数。

- **尾帧提示词**：这一段结尾那一帧用哪句，直接决定尾帧长什么样；留空 = 跟主提示词一样。
- **首帧提示词**：默认折叠，写了专属词才展开。
- 改哪一栏只重画哪一帧（改尾帧词不会把首帧一起重摇）。单独写了首/尾帧词的段，
  卡片那一行会多出 `首帧词` / `尾帧词` 徽章。

| 按钮 | 行为 |
|---|---|
| 只保存（不动关键帧） | 只写该任务 `config.json` 的 `segments[i-1]`；只改秒数时图不用重画 |
| 保存并重画关键帧 | 写配置 + 清掉**受影响那一侧**非 manual 帧的 `sha1` 并起关键帧 worker |
| ☐ 连我自己放的图一起重出 | 仅在段内有 manual 帧时出现；勾上才会撤掉手动图、交给 AI 按新词重出 |

改完提示词，这一段视频的 `generation_sha1` 就变了，下次「继续生成视频」只重跑这一段，
其它段复用。顶栏的下拉框可以切换查看最近的任务（没有 `h3_job_id` 时会自动挂到最新的一个）。

几条规则：
- 帧左下角有来源标签：`AI 生成 / 已替换 / 指定首帧 / 定格 / 开场草案`- **链式段的「开始」帧不能单独重画**（它是上一段的真实尾帧），只能替换
- 「定格」尾帧（= 首帧）同理不能单独重画
- 点「重画」会**立刻**后台重画这一帧（换 seed），并顺着链式关系把下游继承帧一起更新；
  画完自动回到待确认状态
- **重新打开以前的任务**：关键帧齐全但视频没跑完（中断/失败/闸门之前的老任务）时，横幅会变成
  「关键帧已就位，可以继续生成视频」，点「继续生成视频」接着渲染，**关键帧一张都不会重画**；
  帧还没画全的任务则会显示「继续生成关键帧」
- 不想暂停：`stage` 选「一次跑完（不暂停）」
- 关掉节点后想继续：`stage` 选「继续生成视频」，填 `resume_job_id`（面板会自动帮你填上次的任务 ID）

命令行等价操作：
```bash
python run_h3_long_video.py --stage keyframes     # 只出关键帧并暂停
python run_h3_long_video.py --stage videos        # 用已确认的关键帧出片
python run_h3_long_video.py --stage all           # 一次跑完（等价旧行为）
```

### S4.6 关键帧是怎么来的（决定了它为什么会「画歪」）

> 注意本节讲的是**Director 自己生成关键帧**的路径。如果你用 `pipeline.py push`
> 把 Qwen 出的图（或你自己的图）灌成 `segNN_*_manual.png`，下面这套「5 秒草稿」
> 根本不跑，关键帧就是你给的那张——画歪与不歪取决于那张图本身。

关键帧**不是**文生图，而是「一段短草稿视频的第 0 帧 / 最后一帧」：

| 帧 | 怎么生成 | 取哪一帧 |
|---|---|---|
| 段首帧 | `start_frame_prompt` + 3 张参考图，无首帧约束 | 草稿第 0 帧 |
| 段尾帧 | `end_frame_prompt` + **以段首帧为 first_frame** | 草稿最后一帧 |
| 链式段首帧 | 直接复用上一段尾帧（同一个文件） | — |

草稿长度 = `keyframe_draft_seconds`（默认 5.0 秒）。**这是关键约束**：尾帧只有
5 秒的「演化预算」，却常常被要求表达 12~18 秒的动作终点。预算不够时，模型会走捷径——
把镜头拉近、改景别、改表情，甚至换脸，来「看起来像」终点。表现就是尾帧人物突然变大、
下一段开场倒退、整条链越走越贴脸。

三条对策（都已默认开启）：

| 配置 | 默认 | 作用 |
|---|---|---|
| `keyframe_draft_seconds` | 5.0 | 演化的时间预算。原来 2.0 太短，跨度大的动作必崩 |
| `keyframe_camera_continuity` | true | 往尾帧 prompt 尾部追加「镜头跟随、保持同样的景别和全身入镜」 |
| `video_camera_continuity` | false | 把同一段跟拍指令也写进**视频** prompt（实测对中段推近无效，默认关） |
| `keyframe_reanchor_every` | 1 | 每段尾帧都追加身份重锚定，抑制链式累计漂移 |

**机位指令要写「跟拍」，不能写「锁死不移动」** —— 这条是实测踩出来的：15 秒「走向长椅」
的段落，写 `identical camera position / do not move the camera closer` 时，固定机位下人越走越近，
物理上必然变成胸像（实测四张里出现胸像特写）；改成 `camera dollies with her, same shot size,
full body from head to feet` 后，同样的种子出的是全身、长椅自然落到身侧、脸也和首帧一致。
一句话：**要的是「景别不变」，不是「机位不变」**。

**跨度真的超过草稿预算时，别硬锚尾帧**：在分镜里给这一段加 `"free_end": true`，
它就不生成尾帧、自由收尾，下一段的首帧直接取它渲染出来的最后一帧（面板显示「自由尾帧」/
「待定首帧」占位）。走路、上车、起身离开这类「位移大、终点没法用一张图概括」的段落用它；
坐着、转头、小幅动作仍然用正常的首尾帧锚定。详见 `docs/参数配置.md`。

**提示词写法必须跟预算匹配**：草稿只有 5 秒，就别在 `end_frame_prompt` 里写
「已经走到 10 米外的长椅左侧坐定」；写成「又向前走了几步，长椅明显更近、仍在画面右侧」
才有可能达成。跨度真的很大就**把段拆短**（单段 ≤6 秒），不要指望一张尾帧跨越 15 秒。

参考图也有讲究：**至少要有一张全身正面照**（同服装）。三张全是头肩近景时，模型没有
身体比例/裤鞋的依据，一旦要「全身远景」就只能编，景别会跳。另外参考图之间表情要统一，
一张露齿笑的图很容易在低步数采样下「赢」掉其他两张，让人物越走越像那张笑脸。

### S5 全量渲染
- 参数用「标准档」（见第 3 节）
- UI 跑或 `python run_h3_long_video.py`

### S6 QA 判读
看 `<jobs_dir>/<job>/qa_report.json`（`jobs_dir` 默认
`D:/Comfy-Desktop/ComfyUI-Shared/output/h3-long-video/jobs`）：
- `first_frame_ssim` / `last_frame_ssim` **≥0.55 为正常**（新指标已消除分辨率假告警）
- 低于 0.55 的段 = 真漂移，列入重渲名单
- `motion.static_ratio` 是新增的「有没有动」指标：连续抽帧差 <1 的比例，
  **≥0.90 会打 `static_video` 标记**（成片像 PPT 就是这个）。SSIM 看不出来这件事——
  首尾帧都能对上，但中间 10 秒一帧不动
- 成片边界跳变可用抽帧测帧差复核（>25 肉眼可见）

### S6.5 二采后处理重做（不重新渲染）
`two_pass_fix_opening_frames>0` 时，每段出片后会用锚点帧盖住开头几帧再淡入。
这个后处理（以及拼接）可以单独重跑，完全不碰 ComfyUI / 不占 GPU：

```bash
python run_h3_long_video.py --config <jobs_dir>/<job>/config.json --stage reencode
```

它按 `state["segments"][i]["raw_video"]`（模型原始输出，一直在磁盘上）重新生成
`segment_<id>_two_pass.mp4`，然后走正常的拼接/QA 流程。前提是 `raw_video` 还在；
被手工清过的老任务没法救。

> **踩过的坑（2026-10-30）**：修复滤镜的淡入权重写反了
> （`clip((fix+blend-N)/blend)` 而不是 `clip((N-fix)/blend)`），锚点帧的权重从 1 一路降到 0
> 并**永远停在 0**，于是每段 6 帧之后全变成那张静止的锚点图——成片成了带声音的 PPT。
> 现在 `repair_blend_weight()` 有单测锁住这个斜坡，QA 也会用 `static_video` 直接报出来。

### S7 定点重渲
只重跑坏段，不动其他段：
```bash
python run_h3_long_video.py --from-segment 3 --to-segment 3 --force
```
想换风格/运气：`--random-seed`；想复现：`--seed <原seed>`。

### S8 后期（剪映）
调色、音乐、字幕、运镜（推拉摇移放这里做，比让模型生成稳得多）。

## 3. 参数三档（按阶段切换，不必全程精修）

| 档位 | megapixels | two_pass | two_pass_steps | steps | 用途 |
|---|---|---|---|---|---|
| 预览档 | 0.2 | **false** | - | 4 | S3/S4 验证分镜，快速迭代 |
| 标准档 | 0.3 | true | 3 | 6 | S5 全量出片（当前 config） |
| 精细档 | 0.4 | true | 4~5 | 6~8 | 成品交付、单条要质量 |

`final_width/final_height` 保持 **832×1472**（= 0.3MP × 二采 2 倍），走无损拼接。
若改 `megapixels`，final 尺寸要同步改成「一采尺寸 × two_pass_scale」，否则会多一次转码并轻微拉伸。

## 4. 提示词骨架（直接套）

**开场段**
```
同一成年女性从<位置>向镜头缓慢走来。严格保持参考图中的身份、脸型、黑色长发、
<服装>、<鞋>，身高和身体比例不变。9:16 完整全身镜头，固定全身机位，摄影机不推进、
不后退、不缩放；头顶、裙摆和鞋底始终完整入镜。面部平静中性，双唇自然闭合。
<场景描述>，柔和自然日光。
```

**延续段（只写变化）**
```
延续上一段真实尾帧，同一成年女性<新动作>。摄影机保持与第一帧完全相同的固定全身机位。
<细节动作>。双唇闭合、嘴角平直，不微笑、不张嘴。<环境/光影变化>。
```

**切点段（换场景）**
```
<新场景>中，同一成年女性<动作>。严格保持参考图中的脸型、发型、<服装>。
摄影机固定，9:16 全身构图。<氛围>。
```

恒定要带的三条保险：
1. 「延续上一段真实尾帧，不得重新摆姿势」
2. 「摄影机不推进、不后退、不缩放」
3. 「双唇闭合、嘴角平直、不微笑、不张嘴」（这条防嘴部变形很有效）

## 5. 常见故障 → 处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 画面糊、塑料感 | 没开二采 / megapixels 太低 | 标准档：0.3 + two_pass |
| 段落边界跳变 | 链式硬切且首帧没接上 | 二采会自动修（`fix_opening_frames=2`）；仍明显就改切点 |
| 后半段脸不像了 | 链条身份漂移 | `keyframe_reanchor_every: 3~4` |
| 手/脚崩坏 | 单段太长或动作太复杂 | 拆段到 6 秒；简化动作；试 `stabilize_full_body: true` |
| 嘴角/眼睛抽搐 | 模型嘴部不稳定 | 提示词里加死「闭合、平直、不变」 |
| 跑太慢 | 二采 + 高分辨率 | 先用预览档定分镜，再上标准档 |
