
# H3 视频提示词编写规范与范例

## 一、文档用途

本文用于规范 H3 视频生成提示词的编写方式，重点提升人物身份稳定性、动作连续性、空间关系、摄影机运动以及眼神和表情的真实感。

后续生成或优化视频提示词时，默认遵循本文规范。除非明确要求，否则不擅自修改原 JSON 中的配置字段和配置值。

> **流程自动自检**：出片台 / `run_selflift.py` 已在跑 `seg` / `all` 时自动按本规范（重点第八章 眼神/表情）自检每段 `head` / `tail` / `body`，发现「纯眼神下垂无眼神光」「缺自然眨眼」「瞪视/直勾勾」等不合理、不真实的写法会打印告警并提示如何修改（`check` 子命令可单独跑一遍不生成）。告警不阻断生成，按提示改完再重跑即可。

## 二、基本原则

1. **保留原始 JSON 配置**：保留原有结构及所有配置字段，不擅自修改 `title`、`seconds`、`fps`、`seed`、`link`、`ref_images`、工作流路径、模型名称等。通常只优化全局 `head`、`tail` 及各分段的 `head`、`body`。
2. **人物参考图职责明确**：人物参考图用于锁定人物身份，包括脸型、五官、发型、服装、身材比例与整体气质。
3. **场景参考图职责明确**：场景空镜用于锁定空间结构、道路、建筑、背景物体、环境布局及光源方向。
4. **人物运动是主线**：人物运动轨迹明确，摄影机适应人物运动，背景服从统一空间关系。
5. **描述可观察的动作**：优先描述身体、手部、肩部、脚步、视线、表情等可观察变化，避免抽象或含糊的情绪词。
6. **提示词简洁且不矛盾**：避免重复、冗长以及互相冲突的动作或镜头要求。

## 三、人物方向与空间关系

- 明确人物在画面中的位置，例如画面左侧、右侧、中央、前景或背景。
- 明确身体朝向、面部朝向、前进方向及运动轨迹。
- 多人场景明确人物之间的左右、前后、距离及相对位置。
- 禁止无剧情依据地反向、掉头、横移、交换站位或突然改变身体朝向。
- 若剧情确实需要转身或改变方向，必须描述完整过程：脚步调整、肩部转动、上半身转向、最终朝向，避免动作突然跳变。

## 四、摄影机与镜头轴线

- 明确摄影机位置、观察侧别、高度、距离、景别及运动方式。
- 固定镜头轴线和观察侧；禁止无剧情依据地跨轴、180°环绕、突然切换至人物另一侧。
- 摄影机运动应与人物运动匹配。例如人物向画面右前方行走，摄影机在同侧跟拍，保持合理的相对距离与构图。
- 人物位置、背景运动和摄影机运动应符合统一空间关系，不能出现人物方向与背景运动相互矛盾。
- 镜头变化时明确：**只改变摄影机，不改变人物运动状态**。

## 五、人物、摄影机与背景运动关系

分别描述三类运动：

1. **人物运动**：行走、停步、转身、抬手、视线变化等。
2. **摄影机运动**：跟拍、推近、拉远、轻微调整构图等。
3. **背景运动**：道路、建筑、车厢、其他乘客等随空间关系产生的相对运动。

三者必须保持逻辑一致。例如人物持续向前行走，摄影机以接近人物速度跟拍，人物在画面中的位置相对稳定，背景按合理方向移动。

## 六、分段首尾帧与动作连续性

- 每段首帧必须继承上一段**真实生成的最后一帧**，包括人物位置、身体朝向、步态周期、手部位置、摄影机位置/高度/侧别、构图及背景运动方向。
- 不使用重新生成的“相似截图”替代真实尾帧作为连续性依据。
- 段首约 0.5 秒作为动作承接区：沿上一段轨迹继续，不重新起步、摆姿势、改变速度或方向。
- 段尾约 0.5 秒作为自然交接区：明确人物、手部、身体朝向、摄影机、构图及背景的最终状态。
- 人物动作和步态应连续，不因切换景别而重新开始动作。
- 如果平台支持真实尾帧作为下一段首帧输入，应优先使用该方式；文字描述只能辅助约束，不能保证绝对一致。

## 七、镜头景别变化

连续动作中可以依次切换面部、上半身、腰部、腿部等观察范围，但必须明确：

- 变化的是摄影机高度、距离、焦段或构图。
- 人物的行走、站立、身体朝向、手部状态及动作节奏保持连续。
- 不因镜头切换而改变人物位置、动作方向或步态周期。
- 切换前后保持同一空间观察侧，避免跨轴。

## 八、H3 眼神 / 表情提示词规范

### 8.1 禁止只写“眼神下垂 / 空洞”

单独写“眼神下垂”“眼神空洞”容易使眼神变得死板、木然，像定格画面。应提供明确的动态信号和视线落点。

### 8.2 眼神必须包含三件套

1. **自然眨眼**：写明“眼睛自然地眨动”，为模型提供眼部动态信号。
2. **眼神光**：写明“瞳孔带细微反光点（catchlight）”，使眼睛具有真实光泽与神采。
3. **情境化视线落点**：
   - 害羞、警觉、收敛、隐忍：视线微微低垂，落在身前空间。
   - 坚定、交流、回应：视线聚焦前方或对方，但避免直勾勾瞪视。
   - 根据具体动作和情境描述视线的轻微变化，不要让目光长时间固定不动。

### 8.3 表情克制但不能木然

- 使用细微、真实、可观察的变化，例如眉头轻微收紧、嘴唇自然闭合、嘴角轻微变化、呼吸起伏、眼睑细微变化。
- 表情应与情境一致，避免夸张瞪眼、大喊、露齿大笑、嘟嘴或舞台化表演。
- 情绪通过微表情和身体状态体现，不依赖夸张表演。
- 如果参考图本身眼神空洞，应优先修正参考图，再调整动态提示词。

### 8.4 可套用眼神 / 表情句

> 她的眼睛自然地眨动，视线微微低垂、落在身前空间，目光柔和沉静、带细微眼神光（catchlight），不出现眼神空洞或木然。眉头轻微收紧，嘴唇自然闭合，表情真实克制，没有夸张表演。

纯“聚焦前方 + 眼神光”容易产生摆拍感；结合适度自然低垂和轻微视线变化，通常更接近真人状态。

## 九、完整分段范例

以下为一个简化的连续行走范例。重点演示人物方向、摄影机轴线、动作连续性、眼神动态及段尾交接。实际使用时应将每段真实生成的尾帧作为下一段首帧。

### 场景：女生沿校园林荫路自然行走

**人物与场景约束**

- 人物参考图锁定女生身份、脸型、五官、发型、服装、身材比例与气质。
- 场景参考图锁定校园林荫路、道路走向、树木、建筑及光线方向。
- 女生沿道路向画面右前方持续行走，身体朝向与前进方向保持一致。
- 摄影机始终位于女生右侧斜后方，不跨轴、不环绕、不切换至另一侧。
- 人物运动是主线，摄影机适应人物运动，背景保持统一空间关系。

### 分镜 01：中景跟拍

**首帧承接**：女生已经处于自然行走状态，沿画面右前方继续前进，不重新起步。

**动作**：女生步伐自然、节奏稳定，双臂随步态轻微摆动，肩膀放松。她的眼睛自然地眨动，视线微微低垂、落在身前道路空间，目光柔和沉静，瞳孔带细微反光点（catchlight）。表情真实克制，眉头与嘴唇保持自然状态，不出现夸张表演。

**机位**：摄影机位于女生右侧斜后方，齐腰至胸部高度，中景缓慢跟拍。摄影机速度与人物接近，女生在画面中的位置相对稳定，背景树木和道路自然向后移动。

**段尾交接**：女生继续向画面右前方行走，步态、手臂摆动和身体朝向保持连续。摄影机维持同侧跟拍，构图稳定。

### 分镜 02：面部近景

**首帧承接**：严格继承分镜 01 的真实最后一帧，女生行走方向、步态周期、身体朝向及摄影机侧别不变。

**动作**：女生继续自然行走，头部随步伐产生轻微自然起伏，不刻意摆头。眼睛自然地眨动，视线微微低垂并落在身前空间，随后轻微向前调整，瞳孔带细微眼神光（catchlight）。眉头轻微收紧，嘴唇自然闭合，表情细腻、沉静，不木然、不夸张。

**机位**：摄影机仅向前缓慢推近并调整为面部近景，保持女生右侧斜后方的观察侧与原镜头轴线。人物运动状态不变，不因镜头推近而停止行走或改变方向。

**段尾交接**：女生仍在连续行走，眼神和面部微表情保持自然动态。摄影机稳定在面部近景，保留下一段可继承的真实尾帧。

### 分镜 03：上半身近景

**首帧承接**：使用分镜 02 的真实最后一帧。女生继续原有步态、方向和速度。

**动作**：女生的肩膀随步伐轻微起伏，手臂自然摆动，衣物产生细微运动。眼睛自然地眨动，视线轻微低垂、落在身前空间，瞳孔带细微眼神光（catchlight）。眉头轻微收紧，嘴唇自然闭合，表情真实克制。

**机位**：摄影机从面部近景缓慢调整为上半身近景，仅改变摄影机距离和构图，不改变人物运动状态。保持原有观察侧，不跨轴。

**段尾交接**：女生继续向画面右前方行走，肩部、手臂及步态运动连续。摄影机稳定停留在上半身近景。

### 分镜 04：腰部与步态细节

**首帧承接**：继承分镜 03 的真实最后一帧，女生的步态周期和身体方向保持连续。

**动作**：重点呈现女生腰部、衣物及手臂随行走产生的自然运动。步幅稳定，身体重心随脚步合理转移，不出现滑步、脚底漂移或突然加速。

**机位**：摄影机缓慢降低并调整为腰部及步态细节构图，保持同侧观察。镜头变化只影响摄影机，不改变人物动作。

**段尾交接**：女生仍按原轨迹持续行走，步态自然稳定，摄影机保持腰部及步态细节构图。

## 十一、执行原则

**人物运动是主线，摄影机适应人物运动，背景服从统一空间关系。**

文字提示负责描述和约束，真实尾帧、首帧输入及连续动作控制负责提高实际连贯性。对于跨段视频，优先保证真实首尾帧继承、人物方向一致、动作连续和镜头轴线稳定。

## 十二、JSON 配置格式规范（segments.json）

本规范约束的提示词都写在 `segments.json` 里。该文件由出片台 / `run_selflift.py` 读写，字段分两类：

- **保留字段**：工作流、模型、分辨率、种子相关、指纹时间戳等，由工具生成或仅在特定界面改。**不要手改、不要删**，否则会生成失败、接缝错位或 stale 误判。
- **通常改字段**：`title` / `head` / `tail` / 每段 `body` / `seed` / `link` / `join_*` / `megapixels` / `aspect_ratio` / `quality` / `ref_images` / `bg_plate` 等，按本规范编辑。

### 12.1 顶层字段

| 字段 | 类型 | 说明 | 类别 |
|---|---|---|---|
| `title` | str | 片名，也用于成片命名 | 通常改 |
| `final_name` | str | 成片文件名 | 通常改 |
| `prefix` | str | 产物前缀，决定 `segments/`、`refs/` 下所有文件名 | 保留 |
| `workflow` | str(路径) | 工作流 JSON 路径 | 保留 |
| `clip_name` | str | 模型文件名（如 `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors`） | 保留 |
| `ref_image` | str(路径) | 老写法：单人人物参考图 | 保留 |
| `comfy_ref_name` | str | 拷进 ComfyUI input 的参考图文件名 | 保留 |
| `bg_plate` | str | 空镜板 comfy 名（可空 `""`） | 通常改 |
| `bg_plate_path` | str(路径) | 空镜板本地路径 | 保留 |
| `bg_plate_seed` | int | 空镜板生成 seed（默认 913755） | 保留 |
| `chain_first_frame` | bool | 是否链式承接上段尾帧作首帧 | 保留 |
| `fps` | int | 帧率（默认 24） | 保留 |
| `seconds` | float | 每段时长（秒），与 `length` 配套 | 通常改 |
| `length` | int | 帧数 = `fps * seconds`，工具自动算 | 保留 |
| `join_black_seconds` | float | 段间黑场时长 | 通常改 |
| `head` | str | 全片公共前缀提示词（身份/场景锚） | 通常改 |
| `tail` | str | 全片公共后缀提示词（画风/衔接锚） | 通常改 |
| `segments` | list | 分段列表，见 12.2 | 通常改 |
| `join_mode` | str | 拼接方式：`cut` / `auto` | 通常改 |
| `join_dissolve_seconds` | float | 叠化时长（默认 0.25） | 通常改 |
| `film_id` | str | 片 ID | 保留 |
| `megapixels` | float | 输出百万像素 / 分辨率（默认 1.0） | 通常改 |
| `ref_images` | list[{path,comfy_name,label}] | 多人参考图；单人也可走这里 | 通常改 |
| `aspect_ratio` | str | 画幅比例，如 `9:16 (Portrait Widescreen)` | 通常改 |
| `quality` | str | 画质档位：`fast` / `standard` / `high` | 通常改 |
| `*_updated_at` | float(epoch) | 指纹时间戳（`head`/`res`/`quality`/`join` 等），由工具维护，决定 stale | 保留（勿手改） |

### 12.2 segments[] 每段字段

| 字段 | 类型 | 说明 | 类别 |
|---|---|---|---|
| `id` | str | 段号，如 `s01` | 保留 |
| `title` | str | 段标题 | 通常改 |
| `seed` | int | 随机种子（100001–999999，避开 100000 坏种子） | 通常改 |
| `body` | str | **段正文提示词**，按本规范第二～八章编写 | 通常改 |
| `head` | str(可选) | 段级 head，**整段覆盖**全局 `head`（不是追加） | 通常改 |
| `tail` | str(可选) | 段级 tail，覆盖全局 `tail`（常用于单段单独调画风） | 通常改 |
| `link` | {mode,transition} | 承接方式：`chain`=像素承接上段尾帧 / `transition`=独立+转场；`transition`∈`dissolve`/`black`/`cut` | 通常改 |
| `updated_at` | float(epoch) | 本段指纹，工具维护 | 保留 |
| `ref_images` | list(可选) | 段级参考图覆盖（多人/特殊段用） | 通常改 |
| `first_frame` / `first_frame_override` | str(可选) | 本段首帧图；`*_override` 为面板指定 | 通常改 |
| `last_frame_override` | str(可选) | 锁定本段尾帧图 | 通常改 |
| `bg_plate` / `bg_plate_path` | str(可选) | 段级空镜覆盖 | 通常改 |
| `ref_video` / `ref_video_seconds` | str/float(可选) | 视频软参考（动作/机位） | 通常改 |
