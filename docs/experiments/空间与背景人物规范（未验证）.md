## 十三、空间关系、物体连续性与防穿模规范（H9）

> ⚠️ **实测未验证有效（2026-11-13，s02 段 A/B 对照）**：在 H3 上加本规范文案后，输出整段构图/取景发生**不可控偏移**（逐帧灰度 MAE≈56/255），但**未观察到**「手指完整包裹杆体、不穿模、不残留肢体」等针对性改善。H3 只对 catchlight/眼神这类**局部静态外观**有稳定响应，无法做手指级精细空间控制。当前**不建议作为强制规范并入**；保留供参考。若确需防穿模，应改用参考图约束或后处理，而非提示词文本。

### 一、核心原则
人物、肢体、场景和环境物体必须处于同一个稳定的三维空间中，遵循真实的空间位置、遮挡关系、接触关系和物理边界。
人物与物体之间的关系必须连续、明确。不能因为人物动作、摄影机运动或镜头切换而发生空间关系错误。
人物可以接触、抓握、推动、经过或离开物体，但必须符合真实的动作过程。禁止出现肢体残留、身体穿透物体、物体与人物融合或空间位置突然跳变。

### 二、肢体完整性与物体连续性
1. 人物的每只手、手臂、腿和脚都必须保持完整，不能出现多余肢体、残留肢体或肢体复制。
2. 人物松开物体后，必须完整解除接触关系，手部与物体分离，不允许物体上继续残留手掌、手指或肢体轮廓。
3. 人物移动手部时，原接触位置必须同步解除，不允许同一只手同时出现在两个位置。
4. 手部抓握、松开和重新抓握必须有连续的动作过程，不能直接跳变。
5. 人物与物体接触时，接触位置应保持稳定；解除接触后，物体恢复自身完整形态。
6. 不允许人物的身体部位与环境物体融合，不能出现多余手指、重复手掌或肢体分裂。

### 三、空间边界与防穿模
1. 桌子、椅子、扶手、吊环、门框、墙壁等固定物体具有明确的空间位置和实体边界。
2. 人物头部、躯干、手臂和腿部不能穿过这些物体。
3. 人物经过障碍物时，应沿合理的可通行空间移动，不允许直接穿越桌面、椅背、墙壁或其他实体。
4. 人物与物体接触时，应遵循真实的前后、上下和内外空间关系。
5. 吊环、扶手等物体具有固定的几何形状和位置，人物头部、颈部及其他身体部位不能穿过其实体结构。
6. 人物与物体发生遮挡时，应保持正确的前后遮挡关系，不能出现人物肢体突然出现在物体内部或另一侧。
7. 摄影机改变角度或距离时，不能改变人物和场景物体之间原有的实际空间关系。

### 四、人物运动路径与障碍物约束
1. 人物运动必须沿合理的空间路径完成，明确人物从哪里出发、经过哪里、最终到达哪里。
2. 人物行走时，应避开桌子、椅子、墙壁和其他障碍物，不允许身体直接穿过障碍物。
3. 人物转身、侧移、弯腰或伸手时，应考虑周围物体的位置和可活动空间。
4. 人物身体与周围物体之间应保留合理的物理距离，不出现身体嵌入桌面、椅子或其他物体的情况。
5. 如果原有场景空间不足以完成某个动作，应调整动作幅度或运动路径，而不是让人物穿过物体。
6. 禁止为了完成动作而擅自移动、缩放或改变固定场景物体的位置。

### 五、接触动作的连续性
对于抓握、松开、扶持、倚靠、坐下、站起等动作，必须明确接触关系的建立、保持和解除。
例如：
**抓握吊环：**
- 手掌从自然位置移动至吊环。
- 手指逐渐弯曲，形成完整抓握。
- 手掌与吊环保持合理接触。
- 手臂、手腕和肩膀形成自然受力关系。
**松开吊环：**
- 手指逐渐放松并依次解除抓握。
- 手掌与吊环完整分离。
- 手臂自然向下移动至最终位置。
- 吊环恢复完整独立形态，不保留手掌或手指。
- 人物手部只存在于当前实际位置，不出现残影或复制。

### 六、跨帧空间一致性
1. 人物、肢体和固定物体在连续帧中保持稳定的空间位置关系。
2. 人物移动时，所有肢体跟随同一个人物整体运动，不能出现局部肢体滞留在原位置。
3. 固定场景物体保持几何形状和空间位置稳定，不因人物接触而无故变形、复制或消失。
4. 人物与物体之间的遮挡关系随真实运动自然变化，不能无原因地前后交换。
5. 不允许人物穿过物体后突然出现在物体另一侧。
6. 镜头切换和景别变化不能造成肢体数量、人物位置或物体形状发生变化。

### 七、反向约束
严格避免以下生成错误：
- 手已经放下，原物体上仍残留一只手。
- 同一只手同时出现在两个位置。
- 人物出现多余手指、手掌、手臂或腿部。
- 人物头部、颈部或躯干穿过吊环、扶手、桌子或其他实体。
- 人物行走时直接穿过桌子、椅子、墙壁等障碍物。
- 人物手臂穿过躯干，手指穿过扶手。
- 人物与物体粘连、融合或出现不合理的重叠。
- 固定物体突然变形、移动、消失或复制。
- 人物移动后，原位置仍然残留身体部位。
- 摄影机运动导致人物与物体的前后关系发生错误。

### 八、执行要求
1. 优先保持人物肢体完整性和场景物体几何结构稳定。
2. 对所有接触动作明确描述接触建立、持续和解除过程。
3. 对人物移动明确运动路径和周围障碍物的位置。
4. 对固定物体明确其空间位置、形状和不可穿越的实体边界。
5. 对跨段视频继承人物、肢体和物体的真实尾帧状态。
6. 当动作容易造成穿模时，优先简化动作幅度和运动路径，不要通过夸张动作增加生成难度。
**最终原则：人物与环境必须共享同一个稳定的三维空间。人物可以接触物体、绕过物体、离开物体，但不能穿透物体、复制肢体或在原位置留下身体残影。**

## 十四、背景人物与群体行为自然度规范（H10）

> ⚠️ **实测未验证有效（2026-11-13，s02 段 A/B 对照）**：在 H3 上加本规范文案后，输出整段构图同样**大幅偏移**（整帧灰度 MAE≈60/255），但**未见**背景人物「更自然 / 更独立 / 不抢焦点」的针对性改善。H3 对**时间动态类文本**（眨眼、呼吸、群演微动态）无稳定响应（见 D/E/F 实测）。本规范当前**不建议作为强制规范并入**；保留供参考。若需控背景人物，应主要靠场景参考图/参考视频，而非提示词文本。

### 一、核心原则
周围无关人物应当像真实生活环境中的普通人一样，自然地存在于场景中。
背景人物不是静态布景，也不是需要刻意表演的配角。每个人应保持符合当前场景、身份和行为目的的自然状态。
背景人物的动作应当轻微、分散、相互独立，形成真实的生活氛围，不应出现集体静止、集体注视、同步动作或机械重复。
背景人物始终服从主剧情，不得无故抢夺视觉焦点或干扰主要人物的动作。

### 二、背景人物的自然动态
1. 背景人物不能长时间像照片一样完全静止，应保留自然的身体微动作。
2. 站立的人可以有轻微的重心调整、自然呼吸、偶尔眨眼、视线变化和细微姿势调整。
3. 坐着的人可以自然地观察周围、低头看手机、阅读或保持放松的坐姿。
4. 行走的人应保持合理的步态、速度和运动方向，不出现滑步、原地踏步或突然改变方向。
5. 人物之间的动作应具有独立性，不要求所有人同时活动，也不能出现明显的同步动作。
6. 背景人物的动作幅度应符合当前场景，不要为了表现动态而频繁摇头、晃动身体或挥舞手臂。

### 三、视线与注意力分布
1. 背景人物不应全部看向主角、摄影机或同一个方向。
2. 每个人应根据自身行为目的拥有合理的视线落点，例如看手机、看前方道路、观察窗外、与同行者交流或自然观察周围。
3. 背景人物可以偶尔注意到主要人物，但不能所有人同时转头注视主角。
4. 没有剧情依据时，背景人物不要持续盯着镜头。
5. 眼睛自然地眨动，瞳孔带细微反光点（catchlight），视线有轻微自然变化，不出现空洞、呆滞或直勾勾凝视。
6. 背景人物的面部表情保持自然放松，与当前场景氛围一致。

### 四、群体行为与人物差异
1. 不同背景人物应有各自独立的姿势、动作和注意力方向。
2. 避免多人保持完全相同的站姿、坐姿、手部动作或面部表情。
3. 不同人物的动作节奏应有所区别，不出现整齐划一的同步转头、同步眨眼或同步移动。
4. 人物之间应保持合理的社交距离和空间关系，不出现不自然的聚集、重叠或身体穿插。
5. 相邻人物可以有轻微互动，例如简单交谈、观察手机、自然让行，但不应无故增加明显的剧情行为。
6. 背景人物的年龄、服装、姿态和行为应与场景环境相匹配，避免所有人呈现相同的模板化外观。

### 五、不同场景的行为约束
**公交车厢、地铁车厢**
- 站立乘客自然抓握吊环或扶手，身体根据车辆运行产生轻微平衡调整。
- 部分乘客低头看手机，部分乘客观察窗外或前方。
- 坐着的乘客保持自然坐姿，可以有轻微视线和手部动作。
- 乘客之间保持合理距离，不集体盯着主要人物。
- 车辆晃动时，乘客的身体产生轻微且不同步的惯性反馈。
**校园、街道和公共空间**
- 行人保持自然行走速度和合理运动路径。
- 部分人物可以交谈、观察环境、使用手机或等待。
- 不同人物具有独立的行走节奏和视线方向。
- 不要让所有路人朝同一个方向移动或同时停下。
**办公室、会议室**
- 人物根据自身任务自然工作、阅读、使用电脑或交流。
- 不同人物的视线和手部动作应与其当前行为匹配。
- 不要让所有人同时看向主角或摄影机。
- 背景人员保持适度动态，但不影响主要人物的叙事。

### 六、主角与背景人物的关系
1. 明确区分主要人物和背景人物的叙事优先级。
2. 主角执行主要动作时，背景人物保持符合场景的自然活动。
3. 背景人物不应无故模仿主角动作或与主角同步运动。
4. 只有剧情需要时，背景人物才对主角的行为产生明确反应。
5. 如果背景人物注意到异常，应通过合理的视线变化、轻微转头或短暂停顿表现，不要出现夸张围观。
6. 背景人物不能突然走入主角运动路径，也不能无故遮挡主角的重要动作。

### 七、背景人物的空间与连续性
1. 每个背景人物都应保持稳定的身份、外观、服装和空间位置。
2. 背景人物不能在连续帧中突然消失、复制、融合或交换位置。
3. 行走人物应沿合理路径移动，不能突然瞬移或原地滑动。
4. 背景人物与座椅、扶手、桌椅等物体保持正确的接触和遮挡关系。
5. 摄影机移动时，背景人物应符合统一的空间透视和相对运动规律。
6. 背景人物不应因为镜头切换而突然改变姿势、数量或位置。

### 八、反向约束
严格避免以下情况：
- 背景人物像蜡像一样完全静止。
- 所有人都直勾勾盯着镜头或主角。
- 多个人物出现完全相同的姿势和动作。
- 所有人同时转头、眨眼、移动或做出相同反应。
- 人物眼神空洞、面无表情、像机器人一样呆滞。
- 背景人物无意义地摇头、晃动、挥手或反复做同一个动作。
- 行走人物出现原地踏步、滑步、瞬移或运动方向错误。
- 背景人物无故抢占主角视觉焦点。
- 背景人物突然复制、消失、重叠或穿过其他人物。

### 九、执行要求
1. 优先保持背景人物的自然状态和群体行为合理性。
2. 为背景人物提供符合场景的行为方向，而不是为每个人安排复杂剧情。
3. 通过少量、分散、独立的微动作体现生活感。
4. 背景人物的动作强度明显低于主要人物，避免喧宾夺主。
5. 不要求所有背景人物持续运动，允许部分人物自然静止，但应避免整个背景群体呈现统一的僵硬状态。
6. 背景人物的视线、姿态、动作和空间位置必须符合当前场景。
**最终原则：背景人物应当像真实生活中的普通人一样，各自做着自己的事情。自然、独立、适度动态，不集体摆拍，不集体注视，不机械重复，也不抢夺主角的视觉焦点。**
