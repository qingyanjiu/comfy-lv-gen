# 工作流关系

这份文档讲清楚：**哪些工作流、谁喂谁、产出落到哪、想改东西该动哪个文件。**
文件在哪见 `文件位置说明.md`，字段含义见 `分镜JSON.md`。

## 1. 全景：三段流水线

整条链路其实是三件事，每件事都可以单独跑、单独换工具：

```
       ① 出静帧              ② 出动态                 ③ 拼成片
   ┌──────────────┐     ┌──────────────────┐     ┌──────────────┐
   │ Qwen-Image-  │     │ MiniMax H3       │     │ FFmpeg       │
   │ Edit 2511    │ ──> │ 首尾帧插值         │ ──> │ 统一分辨率+拼接│
   │ (改图/转视角)  │     │ (单段 or 多段)     │     │ +淡入淡出     │
   └──────────────┘     └──────────────────┘     └──────────────┘
      example_workflows/    H3 Director 节点         run_h3_long_video.py
      Qwen2511-*.json       + run_h3_long_video.py   的 stitch_segments()
```

关键点：**① 是可选的**。H3 自己也能出关键帧（默认就是这么跑的），Qwen 只是把
「首尾帧长什么样」这件事拿到生图模型上去做，控制力更强、也不用烧 H3 的算力。

## 3. 三条主线的具体关系

### 3.1 单段：一张图就够

```
LoadImage(首帧) ─┐
LoadImage(尾帧) ─┼─> H3SingleClipDirector ──> run_h3_long_video.py（config 里 single_clip = true）
LoadImage(参考×N)┘        │                         │
                          │                         └─> Shared/output/h3_single_clip/long_video.mp4
                          └─> 面板：首尾帧预览 / 进度 / 成片
```

首帧和尾帧是**你给死的**，H3 只负责中间的插值。想改哪一头，就在 `LoadImage` 换图，
或者在面板里直接看结果重跑。细节见 `单段视频.md`。

### 3.2 长视频：关键帧链才是核心

```
LoadImage(参考×N) + 分镜JSON
        │
        ▼
H3LongVideoDirector  ──起 worker──>  run_h3_long_video.py --stage keyframes
        │                                      │
        │                                      ├─ 5 秒 H3 草稿 → 取第一帧当开场帧
        │                                      ├─ 段1 尾帧 = 段1 首帧 + 段1 提示词
        │                                      └─ 段N+1 首帧 = 段N 尾帧（同一张图）
        │                                      ▼
        │                          任务目录/.state.json + keyframes/
        │                                      │
        ├─ 面板「关键帧 → 确认」（可替换 / 重画 / 还原 / 改词）
        │                                      │
        └─ 面板「确认关键帧，生成视频」 ───────>  --stage videos
                                               │
                                               ├─ 逐段 build_graph()（首尾帧插值）
                                               ├─ 二采：修开头两帧条纹
                                               └─ FFmpeg 合并 → long_video.mp4
```

三条容易混的规则：

| 规则 | 含义 |
|---|---|
| `chain_segments = true`（默认） | 段 N 的尾帧**就是**段 N+1 的首帧，同一张图，不是"相似的两张" |
| `continue_from_previous = false` | 这一处是硬切：下一段单独出首帧，两段之间插一段转场（`transition_mode = fade`） |
| 改链上某一帧 | 下游全要跟着重画（`cascade`），面板会标「待同步」 |

细节见 `长视频流程.md`、`分镜JSON.md`、`关键帧生成.md`。

### 3.3 Qwen 出图 → H3 出片：怎么接

这是**最容易被忽略的一条**：关键帧不一定要 H3 自己画。三种接法，从松到紧：

| 接法 | 怎么做 | H3 还画关键帧吗 |
|---|---|---|
| A. 只做首帧 | Qwen 出图 → 存 `Shared/input/` → `H3-Long-Video-Director` 的 `first_frame` 接过去 | 画（开场帧由你定，后续照旧往后长） |
| B. 关键帧全外包 | Qwen 出全部首尾帧 → `pipeline.py push` 灌进任务目录，或面板逐张「替换」→ `stage = 继续生成视频` | **一张都不画**，直接出视频 |
| C. 单段直接给 | Qwen 出首/尾帧 → 接进 `H3-Single-Clip-FirstLastRefs` 的两个 `LoadImage` | 不涉及（单段没有关键帧阶段） |

**用哪一代 Qwen**：2511（4 步，最多 3 张参考，Apache 可商用）和 2.1（8 步 Turbo，最多 10 张参考，
非商用许可）是平级的，换张工作流就行。Director 面板上的 `keyframe_backend` 只记录你选了哪条，
实际出图还是人点对应的工作流。细节和参数见 `Qwen改图.md`。

接法 B 的价值：关键帧的质量和一致性由 Qwen（多图参考、身份锁定）保证，H3 只负责"把两张图
之间连成动作"，省掉 H3 反复抽卡的时间。实测一张 5 秒有声片约 3 分 20 秒（见 `lab/H3-One-Segment.json`）。

## 4. 谁调谁（代码层面）

```
ComfyUI 前端（web/director.js、web/single_clip.js）
        │  fetch /h3-long-video/*
        ▼
director.py  ── 节点 execute() ──> 写任务 config.json
        │                        └─ 起线程 _run_worker()
        │                              │ subprocess
        │                              ▼
        │                     run_h3_long_video.py
        │                              │ HTTP POST /prompt
        │                              ▼
        └──────────────────────> ComfyUI 本体（真正跑模型）
                                       │
                                       └─ 写 output/ → 状态回 .state.json
```

- **前端只跟路由说话**，不 import Python；
- **director.py 不跑模型**，它只写配置、起进程、读状态；
- **run_h3_long_video.py 不碰 UI**，它认 `config.json` 干完全部活；
- 三者之间唯一的契约是**任务目录里的 `config.json` / `.state.json` / `status.json`**。

## 5. 想改东西该动哪

| 想改 | 动这里 | 影响面 |
|---|---|---|
| 模型、分辨率、步数、采样器 | `config.json` 的对应键 | 所有任务 |
| 某一段的提示词 / 秒数 / 二采 | 面板「改词」编辑器（写回任务 `config.json`） | 只影响该任务该段 |
| 关键帧怎么画（步数、草稿时长） | `config.json` 的 `keyframe_*` | 只影响还没跑的任务 |
| 图怎么搭（加节点、改连线） | `run_h3_long_video.py` 的 `build_graph()` / `build_keyframe_graph()` | 全部 H3 出片 |
| 面板长什么样、按钮行为 | `web/director.js` / `web/single_clip.js` | 前端，改完 Ctrl+F5 |
| 路由、任务管理（改名/删除） | `director.py` | 改完必须重启 ComfyUI |
| 分镜结构、字段 | `docs/分镜JSON.md` + `_normalize_storyboard()` | 老任务不受影响（配置已落盘） |

## 6. 常见组合（照着用）

| 目标 | 用哪些 |
|---|---|
| 快速验证一条动作 | `H3-Single-Clip-FirstLastRefs` + 两张图 |
| 5～10 秒、控制力优先 | Qwen 出首尾帧 → 单段节点（接法 C） |
| 30 秒以上长片 | `H3-Long-Video-Director` + 分镜 JSON（默认让 H3 自己长关键帧） |
| 长片但要求角色脸稳 | Qwen 出全部关键帧 → `push` 灌入 → `继续生成视频`（接法 B） |
| 要多角度/多服装参考一起喂 | `Qwen21-Reference-Edit.json`（10 张参考） |
| 只要转个视角、换个衣服 | `Qwen2511-Reference-Edit` / `Qwen2511-MultiAngle-Edit`，不进 H3 |
